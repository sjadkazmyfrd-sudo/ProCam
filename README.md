# ProCam — برنامه دوربین اندروید (CameraX)

## قابلیت‌ها
- عکس و فیلم (MP4)، با ذخیره در گالری (پوشه‌های Pictures/ProCam و Movies/ProCam)
- زوم با دو انگشت، لمس برای فوکوس، لمس طولانی برای قفل فوکوس و نور (AE/AF lock)
- اسلایدر نور (Exposure / EV)
- فلاش (خاموش / خودکار / روشن) در عکس و چراغ‌قوه (Torch) در فیلم
- تایمر ۳ و ۱۰ ثانیه‌ای با شمارش معکوس
- خطوط راهنما (Rule of thirds)
- حالت‌های ویژه (در صورت پشتیبانی گوشی): HDR، شب، پرتره، Retouch، Auto
- کیفیت فیلم: 480p / 720p / 1080p / 4K (بر اساس پشتیبانی گوشی)
- کیفیت عکس: سریع (FAST) یا بهترین کیفیت (HQ)
- ضبط فیلم با صدا، توقف و ادامه ضبط (Pause/Resume)
- دوربین سلفی با خروجی آینه‌ای مثل پیش‌نمایش
- دکمه‌های صدا (Volume) به‌عنوان شاتر
- چرخش درست عکس و فیلم حتی وقتی گوشی افقی گرفته می‌شود
- نمایش آخرین عکس/فیلم و باز کردن آن با لمس
- رابط فارسی و انگلیسی (بر اساس زبان گوشی)

## ساخت فایل APK برای ارسال به دیگران
1. پوشه `ProCam` را در **Android Studio** باز کنید (نسخه Koala 2024.1 یا جدیدتر) و صبر کنید Gradle Sync تمام شود.
2. از منو: **Build > Build Bundle(s) / APK(s) > Build APK(s)**
3. فایل خروجی اینجاست: `app/build/outputs/apk/debug/app-debug.apk`
4. این فایل را برای دیگران بفرستید. گیرنده باید در گوشی خودش نصب از «منبع ناشناس» را برای مرورگر یا پیام‌رسان فعال کند.

برای انتشار در Google Play یا Bazaar: **Build > Generate Signed Bundle / APK** و ساخت امضای اختصاصی.

## نکته
- حداقل نسخه اندروید: ۷.۰ (API 24)
- برای تغییر نام برنامه/پکیج: `applicationId` در `app/build.gradle.kts` و رشته `app_name` را عوض کنید.
